Welcome to SchemaBrake Team Pro.

Your subscription is active. Let’s get your first repository protected in under a minute.

  1. 1

    Create the workflow file

    Create a file named .github/workflows/schemabrake.yml in your repository:

    schemabrake.yml 
    name: Database Safety Check
on:
  pull_request:
    paths:
      - 'prisma/migrations/**'
jobs:
  schemabrake:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: schemabrake/action@v1
        with:
          migrations_path: './prisma/migrations'

    Using Drizzle? Change both paths to drizzle/** and ./drizzle.

  2. 2

    Open a pull request

    Push this file to a branch and open a PR. SchemaBrake will automatically scan your migration directory and post its first report.
