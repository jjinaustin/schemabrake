SchemaBrake
Getting started

Protect your first repository in a minute.

Add one workflow file. Every pull request that changes a migration then gets a safety report before it can merge.

  1. 1

    Create the workflow file

    Create a file named .github/workflows/schemabrake.yml in your repository:

    schemabrake.yml 
    name: Database Safety Check
on: pull_request
permissions:
  contents: read
  pull-requests: write
jobs:
  schemabrake:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: jjinaustin/schemabrake@v1

    SchemaBrake finds Prisma and Drizzle migrations on its own. Keep yours somewhere else? Add with: paths: db/migrations under the last step.

  2. 2

    Open a pull request

    Push this file, then open a pull request that changes a migration. SchemaBrake posts its report as a comment, updates that same comment on every push, and marks each hazard on its line in the diff.
